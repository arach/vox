# vox

> Local-first transcription runtime for macOS apps and developer tools

Follow these steps to install Vox. Ask for approval before running
installation commands.

## Goal

Clone Vox, build the runtime, verify local transcription on macOS.

## Done when

`bun packages/cli/src/index.ts doctor` returns `ready: true`.

## Steps

- [ ] Clone the repository
- [ ] Install dependencies
- [ ] Build the SDK, CLI, and daemon
- [ ] Run tests
- [ ] Verify runtime health

## Prerequisites

- macOS 14+
- Bun
- Swift 6.2+
- Microphone permission if testing live transcription

## 1. Clone the repository

```bash
git clone https://github.com/arach/vox.git && cd vox
```

## 2. Install dependencies

```bash
bun install
```

## 3. Build

```bash
bun run build
```

## 4. Test

```bash
bun run test
```

## 5. Verify

```bash
bun packages/cli/src/index.ts doctor
```

## Run

Proceed with the steps above.
